EPS-TOPIK SIAP KOREA — PWA

FITUR
- Kosakata aktif: kumpulan kosakata awal dari aplikasi Belajar Korea sebelumnya, ditambah kosakata kerja dan keselamatan.
- Mode campuran, kata sulit, semua kata, dan filter kategori.
- Tampilkan jawaban, dengarkan pengucapan dengan suara Korea di browser, tandai kata sudah diingat atau sulit.
- Latihan pilihan ganda 10 soal dan latihan listening berbasis suara teks-ke-ucapan.
- Rencana belajar 6 bulan, rutinitas 60 menit, tautan materi resmi.
- Progres disimpan lokal pada browser/perangkat ini.
- PWA dengan cache offline setelah kunjungan pertama melalui HTTPS.

CARA MENCOBA
1. Ekstrak ZIP.
2. Unggah isi folder eps_topik_web ke repositori GitHub (boleh repositori baru atau folder khusus).
3. Aktifkan GitHub Pages di Settings > Pages, pilih branch dan folder root sesuai lokasi file.
4. Buka URL HTTPS situs. Pada Chrome Android pilih menu ⋮ > Tambahkan ke layar utama atau Instal aplikasi.

CATATAN
- Aplikasi ini merupakan alat bantu belajar pribadi, bukan aplikasi resmi HRD Korea.
- Kumpulan kata campuran awal berasal dari kosakata belajar Korea dan tambahan kosakata bertema kerja; verifikasi makna/konteks dengan buku standar EPS-TOPIK resmi.
- Soal pilihan ganda di dalam aplikasi dibuat untuk latihan, bukan soal resmi atau bocoran. Gunakan buku standar dan contoh soal resmi dari portal EPS-TOPIK.
- Fitur suara bergantung pada dukungan browser dan voice ko-KR yang tersedia. Pengenalan suara pengguna tidak diperlukan di versi ini.
- Data progres disimpan di localStorage browser. Data bisa hilang bila data situs dihapus dan tidak tersinkron antarperangkat.
- Cache offline tersedia setelah situs pertama kali dibuka online; tautan ke materi resmi tetap membutuhkan internet.
